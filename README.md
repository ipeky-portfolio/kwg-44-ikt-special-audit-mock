# KWG §44 Special Audit – IKT (Mock)

This repository simulates a BaFin KWG §44 special audit
with a focus on ICT and IT governance.

## Purpose
- Demonstrate supervisory audit readiness
- Reflect BaFin expectations and audit logic
- Showcase internal audit capabilities in an IKT context

## Focus Areas
- ICT governance and risk management
- Information security
- Business continuity and disaster recovery
- Outsourcing and cloud services

## Disclaimer
This repository is a fictional mock audit for demonstration purposes only.
